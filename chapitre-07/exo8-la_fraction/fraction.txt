Essais : 
$ ./main
 1/2 + 1/3 = 5/6
2/4 reduit = 1/2
0/5 reduit = 0/1
1/-2 = -1/2
1/2 - 2/3 = 1/2
1/2 - 2/3 = 1/3
1/2 / 2/3 = 3/4
 
Égalités : 
2/4 == 1/2 : vrai
Erreur : denominateur null. mise a 0/1
1/2 == 1/3 : faux

Dénominateur nul :
Erreur : denominateur null. mise a 0/1
Fraction(1, 0) = 0/1
Erreur : division par fraction nulle. Mise a 0/1
1/2 / 0/1 = 0/1
mon programme lorsqu'il percoit une fraction avec denominateur null le transforme en fraction "1/0".
je le fais car une fraction avec denominateur null n'a pas de sens, autant mieux la rendre nulle et utilisable plutot que de faire crasher le code.

Invariant : 
mon Invariant est : toute fraction avec un denominateur non null est reduite par le pgcd de ses deux membres.
Il est etabli dans le constructeur, par consequant s'applique a toutes les fractions utilisant la classe "Fraction", et rend le denominateur positif et inverse le signe du numerateur(si le denominateru est positif). A noter qu'il rend aussi le pgcd positif dans le cas il est de signes inverse.
