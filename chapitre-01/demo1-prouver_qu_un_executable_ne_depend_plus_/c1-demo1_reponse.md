Apres l'execution du code suite a la compilation, il n'en ressort aucune erreur ni avertissement de la part du compilateur: l'executable fonctionne parfaitement. Cela demontre qu'un executable est independant de son code source a la suite de sa creation. Livrer un programme n'oblige pas a livrer son code car la machine lit le code binaire final et non le langage de programation original.
