## Rapport:
```
Apres l'execution($ ./main) du programme suite a la compilation($ clang++ test.cpp -o main), il n'en ressort aucune erreur ni avertissement de la part du compilateur quand la source est supprimee($ rm test.cpp): l'executable fonctionne parfaitement. Cela demontre qu'un executable est independant de son code source a la suite de sa creation. Livrer un programme n'oblige pas a livrer son code car la machine lit le code binaire final et non le langage de programation original.
```

* NB: Le terminal utilise est gitbash et le compilateur clang++.
